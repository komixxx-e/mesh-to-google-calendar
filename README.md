## ✨ Возможности

- 🎓 **Поддержка школ и колледжей (СПО)** — распознаёт как школьные уроки, так и пары в колледжах МЭШ, включая номера аудиторий, кабинетов и названия дисциплин.
- 🚀 **Прямой экспорт в Google Календарь** — добавление занятий в один клик через официальный Google Calendar API прямо из браузера (без скачивания файлов).
- 📥 **Скачивание .ics (iCalendar)** — универсальный экспорт без настроек для любых платформ (Apple Calendar на Mac/iPhone, Яндекс Календарь, Outlook).
- ☀️ **Два формата отображения на выбор**:
  - **☀️ Учебный день целиком (1 блок)**: в календаре создаётся одно аккуратное событие на день (например, с `08:30` до `14:15`) с названием `Учёба (X ур.)`, а внутри — полный структурированный список всех пар и кабинетов.
  - **⏰ По отдельным парам**: каждое занятие выставляется отдельным событием со своим интервалом времени и кабинетом.
- 📋 **Предпросмотр занятий** — можно развернуть список перед экспортом и своими глазами убедиться, какие именно пары и кабинеты нашёл скрипт.
- 📊 **Прогресс синхронизации** — наглядная шкала добавления занятий и экран успеха с прямой ссылкой в Google Календарь.
- ⚙️ **Использование со своим Google-аккаунтом** — каждый пользователь может легко подключить свой Google Client ID прямо через иконку шестерёнки в интерфейсе.

## 📖 Как пользоваться

### Способ А: Мгновенный экспорт через `.ics` (Без настроек Google)
*Самый простой способ — работает сразу после установки:*
1. Листайте дни или недели в дневнике МЭШ — счётчик в виджете покажет количество найденных пар.
2. Выберите формат: **☀️ Учебный день** или **⏰ По парам**.
3. Нажмите кнопку **«📥 Скачать .ics»**.
4. Откройте скачанный файл:
   - **На Mac / iPhone**: файл сразу откроется в приложении «Календарь» и предложит сохранить все уроки.
   - **В Google Календаре**: *Настройки ⚙️ → Импорт и экспорт → Импорт → выберите скачанный файл*.
   - **В Яндекс Календаре**: *Настройки ⚙️ → Импорт*.

---

### Способ Б: Прямая отправка в Google Календарь (по API)
*Позволяет отправлять расписание в свой Google Календарь одной кнопкой «🚀 Отправить в Google».*

Для работы прямой синхронизации с вашим личным Google-аккаунтом потребуется один раз создать бесплатный **Google Client ID**:

#### 1. Создание проекта в Google Cloud:
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/) и войдите в свой Google-аккаунт.
2. Вверху нажмите на выпадающий список проектов → **New Project** (Новый проект) → введите имя (например, `MeshCalendar`) → нажмите **Create**.

#### 2. Включение Calendar API:
1. В строке поиска вверху введите **Google Calendar API** и откройте его.
2. Нажмите синюю кнопку **Enable** (Включить).

#### 3. Настройка экрана согласия (OAuth Consent Screen):
1. В левом боковом меню перейдите в **Audience** (или *APIs & Services → OAuth consent screen*).
2. В разделе **Test users** (Тестовые пользователи) нажмите **+ Add users** и **обязательно введите свой Gmail** (это снимет ошибку `403: access_denied`).
3. Нажмите **Save** (Сохранить).

#### 4. Создание Client ID:
1. В левом меню выберите **Clients** (или *Credentials*) → сверху нажмите **+ Create Credentials** → **OAuth client ID**.
2. В поле *Application type* выберите **Web application** (Веб-приложение).
3. В блоке **Authorized JavaScript origins** (Разрешенные источники JavaScript) нажмите **+ Add URI** и укажите:
   * `https://school.mos.ru`
   * `https://dnevnik.mos.ru`
4. Нажмите **Create** и скопируйте полученный **Client ID** (вид: `123456789...apps.googleusercontent.com`).

#### 5. Подключение в скрипте:
1. Откройте страницу МЭШ с расписанием.
2. В правом верхнем углу карточки виджета нажмите иконку шестерёнки **⚙️**.
3. Вставьте ваш скопированный **Google Client ID** и нажмите **«Сохранить»**.
4. Готово! Теперь нажимайте **«🚀 Отправить в Google»** — подтвердите вход через всплывающее окно Google, и скрипт сам создаст отдельный календарь **«Школа (МЭШ)»** и заполнит его занятиями.

## ❓ Частые вопросы (FAQ)

<details>
<summary><b>1. Ошибка 403: access_denied при входе через Google</b></summary>
<br>
Google блокирует вход, если ваш аккаунт не добавлен в список тестировщиков вашего личного проекта.

<b>Решение:</b>
1. Откройте <a href="https://console.cloud.google.com/">Google Cloud Console</a>.
2. В левом меню нажмите <b>Audience</b>.
3. В блоке <b>Test users</b> нажмите <b>+ Add users</b>, введите свою почту Gmail и нажмите <b>Save</b>.
</details>

<details>
<summary><b>2. В счётчике пишет «Ожидание расписания» и уроки не появляются</b></summary>
<br>
Если вы только что открыли страницу:
1. Переключите день или неделю с помощью стрелочек в дневнике МЭШ.
2. Либо нажмите кнопку <b>«🔍 С экрана»</b> в виджете — скрипт принудительно считает пары с открытой страницы.
</details>

<details>
<summary><b>3. Как удалить или отключить расписание из календаря?</b></summary>
<br>
Скрипт не смешивает школьные уроки с вашими личными делами, а автоматически создаёт отдельный календарь с именем <b>«Школа (МЭШ)»</b>.
Вы можете в любой момент скрыть его (сняв галочку в списке календарей слева) или удалить весь календарь в один клик в настройках Google Календаря.
</details>
